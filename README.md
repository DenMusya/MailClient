# Asynchronous Mail Client (IMAP / SMTP)

Асинхронный почтовый клиент на C++ с поддержкой протоколов **IMAP** и **SMTP**, 
реализованный с использованием **Boost.Asio** и **C++20 coroutines**.

---

## ✨ Основные возможности

- Асинхронная работа с почтовыми серверами по протоколам IMAP и SMTP
- Неблокирующий сетевой ввод-вывод (Boost.Asio)
- Использование C++20 корутин (`co_await`, `asio::awaitable`)
- Обработка сетевых ошибок и нештатных состояний
- Чёткое разделение логики протоколов и сетевого слоя
